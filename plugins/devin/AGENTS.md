At the start of each substantive workspace task, check for suggestions before investigating, including when Devin can also find the same work in its own session history. Call the member’s `opencrawl_context_suggestions_v1` MCP tool once with the exact sessionId and eventId in the cue and a brief non-sensitive topic. Use relevant returned evidence and cite its source. Skip trivial requests, private or excluded work, and requests to avoid workspace search. Continue normally if there is no result or the tool is unavailable.

On the opening request in a fresh stock Linux session, the startup hook can finish after the prompt arrives. If no cue has arrived on the opening turn, run this plugin’s `bin/opencrawl-context opening <current Devin session ID>` (beside its bundled CLI) and follow the returned cue if present. If workspace investigation has already begun when the opening cue arrives, make the check before answering. Later turns use their own prompt hook. Use only IDs from a current hook cue. If the opening prompt invokes an OpenCrawl private-session command, pass just that command name as the final argument to the opening helper before working. This preserves privacy on subsequent turns.

Use the opencrawl skill to locate this plugin’s bundled CLI and to perform additional workspace searches when needed.
