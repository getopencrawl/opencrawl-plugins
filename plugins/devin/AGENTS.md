Use this plugin's opencrawl skill for the OpenCrawl CLI and workspace search. It gives the path to the CLI included with the plugin. Use the configured OpenCrawl MCP connection for the signed-in member's workspace.

For substantive workspace work, use the current turn’s OpenCrawl hook cue before investigating. Call the member’s `opencrawl_context_suggestions_v1` MCP tool once with the exact sessionId and eventId in the cue and a brief non-sensitive topic. Use relevant returned evidence and cite its source. Skip trivial requests, private or excluded work, and requests to avoid workspace search. Continue normally if there is no result or the tool is unavailable.

On the first substantive request in a fresh stock Linux session, the startup hook can finish after the prompt arrives. If no cue has arrived on the opening turn, run this plugin’s `bin/opencrawl-context opening <current Devin session ID>` (beside its bundled CLI) and follow the returned cue if present. Later turns use their own prompt hook. Use only IDs from a current hook cue. For a private-session command or a request to disable suggestions for this session, run `bin/opencrawl-context off <current Devin session ID>` and skip automatic checks for the rest of the session.
