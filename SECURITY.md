# Security

Do not include credentials, personal data, transcripts or vulnerability details
in public issues. Use this repository's GitHub private vulnerability reporting
when enabled. If it is unavailable, open a public issue asking for a private
reporting channel without describing the vulnerability. The plugins contain no
secrets and do not need secrets added to their manifests.

Updates to the hosted service and OAuth implementation are separate from package
updates. Revoke the connection in your host when it is no longer needed.
