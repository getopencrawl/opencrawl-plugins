# Directory publication

Each Git marketplace selects its harness directory under `plugins/`. Antigravity can install its directory directly. A GitHub release contains the native platform archives built from those same packages. ChatGPT and Claude web can connect to the hosted MCP endpoint through their connection settings.

For a directory submission, use the exact reviewed tag and native package. Verify install, OAuth and authenticated tool access in that host. Record the submission receipt and live listing URL separately from GitHub release evidence.

The [official MCP registry descriptor](../registry/server.json) describes the hosted HTTP service. Its publication workflow is maintained in opencrawl-core.
